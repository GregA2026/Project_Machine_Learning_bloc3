## A propos des projets 

Ce repository présente 3 projets de Machine Learning :  

- Conversion_Rate_Prediction-Project  
- Uber_Pickups-Project  
- Walmart_Predict_Weekly_Sales-Project  

Les projets seront décris précisément dans leur readme dédié ainsi que l'architecture de leur dossier respectif.  
  
## Architecture du sommaire

```
├── Conversion_Rate_Prediction-Project
├── Uber_Pickups-Project
├── Walmart_Predict_Weekly_Sales-Project
├── .gitignore
├── README.md
├── requirements.txt
```
## Contenu du repository  

📁 Conversion_Rate_Prediction-Project :
  Dossier dédié au projet "Conversion Rate"     

📁 Uber_Pickups-Project :
  Dossier dédié au projet "Uber Pickups"       

📁 Walmart_Predict_Weekly_Sales-Project :
  Dossier dédié au projet "Wallmart Predict Weekly Sales"      

📄 .gitignore :

📄 requirements.txt :  
  Ce fichier liste les librairies Python utilisées dans les notebook ainsi que leurs versions exactes.

## Acquisition du repository

Dans votre terminal, rendez-vous dans le lieu de destination où vous souhaitez que le repository soit stocké localement sur votre machine puis saisissez :  
```powershell  
git clone https://github.com/GregA2026/Project_Machine_Learning_bloc3.git
``` 

## Environnement

Vous devez installer les différentes librairies d'environnement pour exécuter les notebook.
Ecrivez dans votre terminal en étant dans le dossier du repository cloné sur notre machine :  

```powershell  
pip install -r requirements.txt  
```
